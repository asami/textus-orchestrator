# Textus Orchestrator

Textus Orchestrator is the Textus subsystem for participant/capability orchestration across Human, AI agents, deterministic subsystems, and software-development workers.

It is not a replacement for CNCF Workflow, Candidate-Admission, sm-workflow, TEAI, or Textus Control Center.
